Veloce brand assets
===================

Palette
- Ink: #171717
- Paper: #F3F3F1
- Accent blue: #2563EB

Files
- veloce-app-icon.svg and veloce-icon-{16,32,48,128,256,512}.png:
  Rounded-square app icon with transparent corners.
- veloce-mark.svg and veloce-mark-{16,32,48,128,256,512}.png:
  Accent mark on transparent background.
- veloce-mark-monochrome*.svg and veloce-mark-mono-*.png:
  Single-colour mark for tray/menu use; choose dark or light variant.
- veloce-wordmark*.svg / .png:
  Horizontal logo lockup for light or dark backgrounds.

The SVG wordmark uses a system sans-serif font stack. For perfectly identical
typography across systems, convert the wordmark text to outlines in a vector editor
or bundle a licensed font with the application.
